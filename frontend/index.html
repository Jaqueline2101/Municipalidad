Base de datos: database.sqlite (Servidor Backend)

El sistema está configurado para registrar y sincronizar todos los bienes patrimoniales, oficinas, pisos, sedes, trámites y usuarios de manera automática en la base de datos SQLite local del servidor.

Información de Base de Datos Local

La base de datos SQLite se gestiona de forma totalmente autónoma por el servidor local. El archivo físico se encuentra en el directorio backend/database.sqlite.

Para realizar copias de seguridad (backups), simplemente duplica o copia el archivo database.sqlite en un lugar seguro.
